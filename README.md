# WPF2DGame
WPF2DGame is a desktop video game that represents a tile-based 2d game with resources collection (wood and stone).
Game is about collecting all possible stone and wood to pass the level.

## Technologies and Frameworks
### WPF
This is a desktop game built with Windows Presentation Foundation (WPF), using XAML for UI layout and C# for game logic

### .NET 9
Game is coded in .NET 9

## Features
- Menu options with key binding explanation
- Tile-based map generation
- Player can place and break resources
- Possible size change of the map 
- Water tiles as an obstacle
